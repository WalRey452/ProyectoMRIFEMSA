# Región recomendada para AWS: us-east-1

# -------------------------------------------------------------
# INFRAESTRUCTURA (Despliegue en AWS)
# -------------------------------------------------------------
# Opción A — EC2 + PM2
#   - EC2: t3.small o superior (2 vCPU, 2 GB RAM mínimo)
#   - SO: Ubuntu 22.04 LTS
#   - PM2: gestor de procesos Node.js (npm install -g pm2)
#   - Nginx: reverse proxy (puerto 80/443 → 3000 backend, 4200/dist frontend)
#   - Certbot: certificado SSL gratuito (Let's Encrypt)
#
# Opción B — Elastic Beanstalk
#   - Platform: Node.js 20 running on 64bit Amazon Linux 2023
#   - Instance type: t3.small
#
# Opción C — ECS (Docker)
#   - Imagen base: node:20-alpine
#   - Dockerfile incluido en backend/ y frontend/
#
# -------------------------------------------------------------
# PUERTOS DE LA APLICACIÓN
# -------------------------------------------------------------
# Backend (NestJS API):  3000 (interno) → 80/443 (público via Nginx)
# Frontend (Angular):   Servir dist/ como archivos estáticos via Nginx
#                       O ejecutar en 4200 en modo dev
#
# -------------------------------------------------------------
# VARIABLES DE ENTORNO REQUERIDAS EN PRODUCCIÓN
# -------------------------------------------------------------
# Ver README.md sección "Variables de Entorno" para la lista completa.
# Las variables NUNCA deben estar en el código fuente ni en Git.
# Usar AWS Secrets Manager, Parameter Store o un archivo .env
# en la instancia del servidor con permisos restringidos (chmod 600).
#
# -------------------------------------------------------------
# COMANDOS DE DESPLIEGUE
# -------------------------------------------------------------

#   npm install
